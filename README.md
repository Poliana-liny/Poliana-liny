### 📁 Estrutura do portfólio

Cada projeto cobre o ciclo completo de um produto de dados — **geração/coleta → ETL → modelagem em SQL → análise com storytelling → dashboard publicado** — aplicado a um cenário de negócio diferente:

```
portfólio
├── price-guard-intelligence   → Pricing & inteligência comercial (Python + SQL)
│   Precificação, elasticidade, margem e competitividade de 1.156 SKUs;
│   motor de simulação que só recomenda mudança se o lucro projetado subir.
│
├── Ops-Flow                   → Operações / central de atendimento (Python + Streamlit)
│   Storytelling "antes x depois" da implantação de gestão orientada a dados,
│   126 mil chamados, 220 atendentes, dashboard publicado ao vivo.
│
├── call-center-sla-analytics  → Business Intelligence executivo (Power BI)
│   Dois dashboards Power BI: análise de SLA antes x depois e visão executiva
│   de call center com 200 mil casos.
│
└── FleetFlow                  → Logística / transporte CD-a-CD (Python + SQL)
    Custo efetivo x confiabilidade entre 5 transportadoras e comparação
    regional de ocorrências, com dashboard HTML/Chart.js.
```

Em cada repositório, a mesma arquitetura se repete:

```
dados brutos (gerados/fictícios)
        │
        ▼
   pipeline de ETL (Python)
 extract → validate → transform → load
        │
        ▼
 banco de dados (PostgreSQL / SQLite)
        │
   ┌────┴────┐
   ▼         ▼
 SQL       análise com
 (views,   storytelling
 kpis)     (gráficos + relatório)
        │
        ▼
   dashboard interativo
 (Power BI / Streamlit / HTML+JS)
```
